# 造物所 IDEA KIT · 线上版

这个目录是课程网站的线上部署源码。它沿用 `../idea-kit` 的首页、设计流程和灵感集市视觉；`public/` 中是从该项目构建得到的页面与图片。根路径会跳转到 `/index.html`，集市地址为 `/index.html#/inspiration`。

线上版使用 Sites 的 Worker 提供 API，并通过 R2 持久保存玩家作品和上传文件。浏览、搜索、下载对访问者开放；发布作品需要先使用 ChatGPT 登录。每件作品可包含配件表及 1–5 个 PDF、PNG、JPG、WebP 或 ZIP 文件，总大小不超过 25 MB。服务器会核验文件内容与扩展名，并将下载以附件形式提供。

设计方案由服务端调用 DeepSeek 生成。`DEEPSEEK_API_KEY` 作为 Sites 密钥变量保存，浏览器不接触密钥。生成前需登录，每个账号每天最多请求 10 次；服务端只接受零件库里的器件，并自行计算测试参考价。AI 内容与电路、结构和安全性仍需团队实测。官方作品是标注清楚的概念示例。线上购买意向、付款和实物交付尚未开放，也不在线收集联系方式。公开运营前，团队还需要建立投稿审核、举报处理、版权与隐私说明。公开视频和 Google 字体仍依赖各自的外部地址。

`.openai/hosting.json` 保存站点身份与 `BUCKET` 存储绑定。运行时凭据由 Sites 管理，不应写入源码。修改视觉后，先在 `../idea-kit` 构建，再将构建结果同步到本目录的 `public/`；只编辑 `public/` 的线上专属购买页提示时，注意不要被下次同步覆盖。
